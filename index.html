DATA & SOURCES
Interconnector list & locations
Compiled from ENTSO-E's public grid map and Transparency Platform border list (transparency.entsoe.eu), cross-checked against individual project pages for named HVDC links (e.g. NordLink, ALEGrO, Celtic Interconnector, Viking Link). Coordinates mark the approximate converter station / border-crossing area, not exact tower positions.
Technical limits (NTC/thermal)
Approximated from publicly published NTC values (ENTSO-E TYNDP capacity reports, ENTSO-E NTC bulletins, and individual TSO/project announcements). Several TSOs only publish regional or seasonal figures — those are rounded to a single representative value here.
Hourly & date-based loading
Simulated, not live telemetry — a seeded model with diurnal shape, weekday/weekend effect and seasonal baseline, for demonstration only. Swap in real ENTSO-E Physical Flow data via an API token to replace this.
